# AGENTS.md

The antseed strategy substrate has been moved out of this public
repository. It is operator-internal.

The canonical strategy directory lives at:

    ~/antseed-strategy/

That directory is shared across antseed-explorer and antseed-agent.
It holds capability, market, narrative, roadmap, USP, and live state
notes — material that doesn't belong on a public surface.

Operators with access to that directory can read it there. For
everyone else: the code in this repo and the Antfeed explorer at
<https://antfeed.org> together describe what the explorer does.
The strategy doc describes why we do it that way and what comes
next — distinct material, deliberately kept off the public surface.

This file remains here as an anchor so the location is discoverable.
